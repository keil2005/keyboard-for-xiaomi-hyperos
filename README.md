# FoldDeck — 小米 18 Fold 半屏键盘

小米 18 Fold 半折（笔记本形态）下：**上半屏 = 微信等应用，下半屏 = 常驻 MacBook 风格键盘 + 触控板**。

## 功能特性

- **MacBook 风格键盘**：数字行 + QWERTY + 修饰键（Ctrl/⌥/⌘）+ 方向键，主题化键帽 + 背光效果。
- **中英切换**：参考国行 Mac 键盘布局，`中/英` 键（Caps Lock 位）+ `fn` 键双位置切换。
  - 英文模式：字母直出。
  - 中文模式：字母累积拼音 → 流水屏显示候选 → 点候选上屏。
- **流水屏（Touch Bar 风格）**：黑色长条 + 四角圆角，emoji 左右滑动点选 / 拼音候选预览双模式。
- **触控板**：单指移动光标、轻点左键、双指右键/滚动、长按拖拽。
- **鼠标开关**：左下角 🖱 按钮一键开关，关闭时同步隐藏悬浮指针。
- **设置页**：按键声音（3 种音色）/ 震动 / 主题色（5 套）/ 背光效果（呼吸/扫描/按键亮）。
- **背光动画**：呼吸、扫描光带、按键渐灭三种模式。

## 架构

```
┌──────────────────────────┐
│  上半屏：微信等任意 App      │  ← 真实应用
├──────────────────────────┤
│  流水屏（emoji/拼音预览）    │
│  电脑键盘（MacBook 键位）    │  ← DeckActivity（系统分屏下半屏）
│  触控板 + 左下角三按钮       │
└──────────────────────────┘
```

| 组件 | 作用 |
|---|---|
| `DeckActivity` | 键盘面板（系统分屏下半屏），`FLAG_NOT_FOCUSABLE` 防抢焦点 |
| `GhostImeService` | 隐形输入法：抢输入焦点、**屏蔽系统键盘弹出**，打字 100% 兼容通道 |
| `DeckAccessibilityService` | 无障碍：文字写入（ACTION_SET_TEXT）+ 鼠标手势（dispatchGesture） |
| `InputRouter` | 双通道路由：IME 优先 → 无障碍兜底；鼠标总开关 |
| `EmojiBarView` | 流水屏（emoji / 拼音候选双模式） |
| `PinyinEngine` + `PinyinDict` | 拼音输入引擎（398 单字 + 154 常用词，精确 + 前缀匹配） |
| `CursorView` | 悬浮鼠标指针（随开关显隐） |

## 安装（手机端）

1. 把 `fold-deck.apk` 传到 18 Fold，点击安装（首次需允许「安装未知应用」）。
2. 打开 **FoldDeck**，按向导开三项权限：
   - **① 悬浮窗权限** → 允许「显示在其他应用上层」
   - **② 无障碍服务** → 找到「FoldDeck 输入通道」开启（**鼠标手势依赖此项**）
   - **③ 输入法** → 启用并切换到「FoldDeck 隐形输入法」
   每开一项返回本页，圆点变 ✅。
3. 手动分屏：微信上半屏 + FoldDeck 键盘下半屏（HyperOS 无法程序化分屏）。

## 使用

- **半折手机**（笔记本形态），微信在上半屏，键盘在下半屏。
- **左下角三按钮**：⏻ 退出 / ⚙ 设置 / 🖱 鼠标开关（蓝色高亮=开）。
- **中英切换**：按 `中/英` 键（Caps Lock 位）或 `fn` 键，中文模式下该键常亮。
- **中文输入**：打拼音（如 `nihao`）→ 流水屏显示候选字 → 点候选上屏；退格先删拼音、拼音空后删文字。
- **触控板手势**：

  | 手势 | 动作 |
  |---|---|
  | 单指滑动 | 移动鼠标光标 |
  | 轻点 | 左键 |
  | 双指点按 | 右键 |
  | 双指滑动 | 滚动内容 |
  | 长按后拖动 | 拖拽（选文字/拖文件） |

- 组合键：**Ctrl+C/V/X/A/Z** 走无障碍节点动作（复制/粘贴/剪切/全选）。

## 通道优先级

打字自动选择：
1. **隐形 IME 的 InputConnection**（任何输入框 100% 兼容，含微信）
2. 无障碍 `ACTION_SET_TEXT`（IME 未选中时兜底）

鼠标只走无障碍 `dispatchGesture`（点击/滑动/拖拽）。

## 已知边界

- Ctrl+Z 撤销无公开注入 API，暂不支持。
- 极少数自绘输入框不暴露无障碍节点，文字写入失效——切系统键盘临时处理。
- **无障碍服务必须手动开启**（HyperOS 封了 `WRITE_SECURE_SETTINGS`，无法程序化或 shell 注入）。
- HyperOS 4 封禁 `input tap/swipe`、`settings put`、`FLAG_ACTIVITY_LAUNCH_ADJACENT`，分屏需手动建立。

## 构建（Mac）

```bash
cd fold-keyboard && bash build_apk.sh   # 产出 fold-deck.apk
```

免 Gradle，直接用 Android SDK build-tools 33.0.1（aapt2 + d8 + apksigner），与 mecha-apk 同链。
